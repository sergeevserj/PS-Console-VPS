# PS Console — VPS-хостинг

Working page of the PS Cloud Services console (VPS promo), built with the PS Design System.

**Live page:** https://sergeevserj.github.io/PS-Console-VPS/

## Files

| Path | What it is |
|---|---|
| `index.html` | The page. Open it in a browser or serve it with GitHub Pages. |
| `ps-ui.css` | PS Design System tokens and component styles. |
| `ps-console-nav.css` | Styles for the console navigation (left menu, section menu, products panel). |
| `images/` | Hero illustration (`tiz.png`) and background (`div_bg.png`). |
| `source/` | Design source from the claude.ai canvas: `Main.dc.html` (page), `ConsoleNav.dc.html` (navigation component), `canvas.json`. These render only inside the canvas. |

Keep `index.html`, the two CSS files and the `images/` folder together at the repository root.
