# PS Console — VPS promo (design source)

Source of the "VPS promo" design canvas built with the PS Design System.

- `Main.dc.html` — the page (Design Component format: `{{holes}}`, `<sc-if>`, `<sc-for>`, logic in the `text/x-dc` script).
- `ps-ui.css` — PS Design System tokens and component styles used by the page.
- `canvas.json` — canvas layout (artboard size, design system record).

Note: `Main.dc.html` renders inside the claude.ai Design canvas runtime (`support.js`), not as a plain web page.
